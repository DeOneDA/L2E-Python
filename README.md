# L2E-Python 🐍

My personal Python learning repository, documenting my journey as a Fellow
at the **Learn2Earn (L2E) Fellowship** — an intensive, peer-to-peer coding
programme focused on building world-class AI engineering skills.

## 📁 Repository Structure

| File / Folder | Description |
|---|---|
| `Test.ipynb` | Main learning notebook — core Python fundamentals, OOP, data structures, algorithms, iterators and more |

## 🧠 Topics Covered

- Python fundamentals (functions, loops, conditionals, error handling)
- Higher-order functions (`map`, `filter`, `lambda`)
- Object-Oriented Programming (classes, inheritance, dunder/magic methods, MRO)
- Data structures (stacks, queues, linked lists, binary search trees)
- Sorting algorithms (bubble, selection, insertion, merge, quicksort)
- Iterables and iterators
- List, dict and set comprehensions
- Recursion
- String manipulation and parsing

## 🔬 TechyJaunt Sprint Project

Built a **produce loss prediction model** for an agri-tech platform using
Python and scikit-learn. Merged and cleaned 6 datasets (farmer profiles,
cold room data, produce listings, bookings, logistics, reviews), engineered
features, trained separate **Storage Risk** and **Transit Risk** logistic
regression models, and produced state-level risk visualizations.

**Libraries used:** `pandas`, `numpy`, `scikit-learn`, `seaborn`, `matplotlib`
